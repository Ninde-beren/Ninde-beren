## Ce que je fais

**Back-end** — Symfony, API Platform, Doctrine. Je travaille en Domain-Driven
Design : agrégats et invariants dans le domaine, services applicatifs fins,
exposition maîtrisée via API Platform, sécurité au niveau des ressources.

**Front-end** — React et TypeScript strict, MUI, TanStack Query. Découpage par
features, état serveur séparé de l'état d'interface, composants typés de bout
en bout depuis les contrats d'API.

**Exploitation** — Docker, VPS, migrations Doctrine, workers asynchrones,
déploiements et supervision. Je livre jusqu'en production, pas jusqu'au merge.
